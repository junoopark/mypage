# 설계서 — 「투자 전략 히스토리」 타일 (strategy)

소개 페이지 6개 타일 중 중상단 타일의 설계다. 구현 시안이 `frontend/js/strategy.js`에 있다.

## 1. 구성

시장(미국·한국)별로 **10년 금리 선 그래프 + 투자의견 구간(배경 음영) + 호버 툴팁**을 보여준다. "지금 의견이 실제 금리 흐름과 어떻게 맞아떨어졌는지"를 되짚어보는 타일이다 (영문명 Strategy Track Record).

```
■ 적극축소  ▨ 축소  ▦ 중립  ▨ 확대  ■ 적극확대     ← 범례 (한 번만, 두 차트 공용)

미국 10년 금리 및 듀레이션 전략
5.2┤                                          ╱
   │                              ╱╲╱╲    ╱╲╱
   │            ╲    ╱╲    ╱╲╱╲╱
3.8┤ ╲╱╲╱╲╱╲╱
   └──────────────────────────────────────────
    26.1    26.3    26.5    26.7    26.9

한국 10년 금리 및 듀레이션 전략
   (같은 형태)
```

- 배경 음영은 **투자의견 구간**이다. 의견이 바뀐 날짜(`as_of`)부터 다음 의견이 나오기 전까지 한 구간으로 칠한다.
- 마우스를 선 위에 올리면(터치는 드래그) 가장 가까운 데이터 지점에 점이 찍히고, 그 날짜의 **금리 값 + 그 시점의 투자의견**이 툴팁으로 뜬다.

## 2. 색·무늬 체계

「매크로 및 금리 전망」 타일과 **같은 색 토큰**을 쓴다 (`style.css`의 `--neg`, `--neg-soft`, `--neg-strong`, `--pos*`, `--neu*`). 색만으로 구분하기 어려운 경우를 위해 무늬도 다르게 한다.

| 값 | 한국어 | 칠 | 무늬 |
|---|---|---|---|
| -2 | 적극축소 | `--neg-strong` (진한 빨강) | 단색 |
| -1 | 축소 | `--neg-soft` 바탕 + `--neg` 빗금 | 대각선 빗금 |
| 0 | 중립 | `--neu-soft` 바탕 + `--neu` 점 | 점 |
| +1 | 확대 | `--pos-soft` 바탕 + `--pos` 빗금 | 대각선 빗금 |
| +2 | 적극확대 | `--pos-strong` (진한 청록) | 단색 |

무늬는 SVG `<pattern>`(`strategy-hatch-neg` · `strategy-dots-neu` · `strategy-hatch-pos`)으로 한 번만 정의하고 `url(#id)`로 참조한다.

## 3. 데이터 계약 (JSON)

화면이 받는 모양이다. `backend/app/routers/strategy.py`(`GET /strategy`)가 이 모양을 돌려주고, 화면은 `config.js`의 `API_BASE_URL`로 호출한다. `frontend/data/strategy.json`은 지금은 읽지 않는 설계 참고용 표본이다.

```json
{
  "rates": {
    "US": {
      "unit": "%",
      "series": {
        "base": { "label": "미국 기준금리", "points": [{ "date": "2026-01-02", "value": 4.5 }, "..."] },
        "y2":   { "label": "미국 2년",   "points": ["..."] },
        "y10":  { "label": "미국 10년",  "points": ["..."] }
      }
    },
    "KR": {
      "unit": "%",
      "series": {
        "base":   { "label": "한국 기준금리",    "points": ["..."] },
        "ktb3y":  { "label": "한국 국고채 3년",  "points": ["..."] },
        "ktb10y": { "label": "한국 국고채 10년", "points": ["..."] }
      }
    }
  },
  "opinions": {
    "rows": [
      { "market": "US", "asOf": "2026-01-01", "opinion": -2 },
      { "market": "US", "asOf": "2026-03-05", "opinion": -1 }
    ]
  }
}
```

| 필드 | 값 |
|---|---|
| `rates.<시장>.series.<key>.points` | 날짜순 정렬된 `{date, value}` 배열. 백엔드가 FRED(미국)/ECOS(한국)에서 최근 3년치를 받아온다 |
| `rates.US.series` | `base`(기준금리, FEDFUNDS) · `y2`(2년, DGS2) · `y10`(10년, DGS10) |
| `rates.KR.series` | `base`(기준금리) · `ktb3y`(국고채 3년) · `ktb10y`(국고채 10년) |
| 차트에 그리는 것 | 시장별 **10년물**(`y10`/`ktb10y`)만 그린다 (`strategy.js`의 `PRIMARY_SERIES`). 기준금리·2·3년물은 응답에는 있지만 아직 화면에 안 쓴다 — 나중에 만기 선택 UI를 더할 수 있다 |
| `opinions.rows` | 「매크로 및 금리 전망」 타일의 **이력 전체**(현재+과거 모든 행)와 같은 표. `market`/`asOf`/`opinion`은 그 타일과 같은 규칙(-2~+2) |

**`opinions.rows`는 두 타일이 값을 공유한다.** 백엔드가 `database/seed/viewpoint_opinions.csv`를 그대로 읽어서 돌려준다 (`load_opinion_rows()`). DB(`treasury_opinions` 테이블)가 생기면 CSV 대신 그 테이블을 읽도록만 바꾼다.

## 4. 구간(밴드) 계산 규칙

`market`별로 `opinions.rows`를 `asOf` 오름차순 정렬한 뒤, 구간 `i`는 `[rows[i].asOf, rows[i+1].asOf)`로 칠한다. 마지막 구간은 그 시장의 금리 데이터 마지막 날짜까지 이어진다. 첫 의견의 `asOf`보다 이전 구간(금리 데이터는 있는데 의견 이력이 없는 구간)은 칠하지 않는다.

## 5. 호버 동작

- SVG 위에서 `mousemove`(터치는 `touchmove`) 발생 시, x좌표를 날짜로 환산해 **가장 가까운 데이터 지점**을 찾는다.
- 그 지점에 세로 점선 + 점을 그리고, 툴팁에 `{날짜} · {금리}% · {그 시점 투자의견}`을 띄운다 (예: "9/17 · 4.95% · 확대"). 의견 구간 밖이면 "-"로 표시한다.
- `mouseleave`/`touchend`에서 모두 숨긴다.

## 6. 파일

| 파일 | 역할 |
|---|---|
| `frontend/js/strategy.js` | 차트·범례·툴팁을 그린다. `${API_BASE_URL}/strategy`를 호출한다. 언어를 바꾸면 다시 그린다 |
| `frontend/data/strategy.json` | 설계 참고용 표본 (지금은 읽지 않는다) |
| `frontend/css/style.css` | `.strategy*` 스타일과 기존 `--neg`/`--pos`/`--neu` 색 토큰 재사용 |
| `frontend/js/i18n.js` | `strategy.*` 문구 (한국어/English) |
| `backend/app/routers/strategy.py` | `GET /strategy` — 캐시 확인 후 FRED/ECOS 조회 + CSV 이력 병합 |
| `backend/app/services/rates/ecos_client.py`, `fred_client.py` | `G:\내 드라이브\coding\shared`의 클라이언트를 이 프로젝트용으로 축소한 버전 |
| `backend/app/services/rates/cache.py` | 메모리 TTL 캐시 (12시간) |
| `backend/app/services/rates/service.py` | 시리즈 조회 → JSON 포인트 변환, `viewpoint_opinions.csv` 읽기 |
| `backend/.env`(커밋 안 함) | `FRED_API_KEY`, `ECOS_API_KEY` — 로컬은 `.env`, 배포는 Render 환경변수 |

## 7. 다음 단계 (미구현)

- `opinions.rows`를 `treasury_opinions` 테이블 하나로 통합해 「매크로 및 금리 전망」 타일과 값을 공유한다 (DB 붙일 때).
- 기준금리·2·3년물 등 다른 만기를 화면에서 고를 수 있게 할지는 미정 (지금은 10년물만 그린다).
- Render 배포 시 `FRED_API_KEY`/`ECOS_API_KEY` 환경변수를 추가해야 한다.
