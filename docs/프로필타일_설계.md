# 설계서 — 「프로필」 타일 (profile)

소개 페이지 6개 타일 중 우상단 타일의 설계다. 구현 시안이 `frontend/js/profile.js`에 있다.

## 1. 구성

| 순서 | 항목 | 형태 |
|---|---|---|
| 1 | 이름 | 여러 줄 가능 |
| 2 | 직함 / 소속 | 여러 줄 가능 |
| 3 | 소개(약력) | 여러 줄 가능 |
| 4 | 경력 | 여러 개 항목, 항목마다 상세도 여러 줄 가능 |
| 5 | 학력 | 여러 개 항목 |
| 6 | 자격증 / 전문 분야 | 여러 개 항목 |
| 7 | 연락처 / 링크 | 여러 개 항목 |

**모든 항목이 여러 줄·여러 개를 담을 수 있다.** 이름·직함·소개는 줄 단위 배열로, 경력·학력·자격증·링크는 항목(행) 단위 목록으로 여러 개를 담는다.

## 2. 데이터 계약 (JSON)

화면이 받는 모양이다. 지금은 `frontend/data/profile.json` 파일이 이 역할을 하고, 나중에 API(`GET /profile`)가 같은 모양을 돌려주게 한다.

```json
{
  "basic": {
    "name_ko": ["박준우"],
    "name_en": ["Junoo Park"],
    "title_ko": ["Fixed Income Strategist", "OO증권 리서치센터"],
    "title_en": ["Fixed Income Strategist", "OO Securities"],
    "bio_ko": ["채권 시장을 분석하고 전략을 세웁니다."],
    "bio_en": ["I analyze bond markets and build strategies."],
    "avatar": "assets/profile.jpg",
    "avatar2x": "assets/profile@2x.jpg"
  },
  "career": [
    { "org_ko": "…", "org_en": "…", "role_ko": "…", "role_en": "…",
      "start": "2022-03", "end": null,
      "desc_ko": ["…"], "desc_en": ["…"] }
  ],
  "education": [
    { "school_ko": "…", "school_en": "…", "degree_ko": "…", "degree_en": "…",
      "start": "2014-03", "end": "2018-02" }
  ],
  "certifications": [
    { "name_ko": "…", "name_en": "…", "issuer_ko": "…", "issuer_en": "…", "year": "2020" }
  ],
  "links": [
    { "label_ko": "GitHub", "label_en": "GitHub", "url": "https://github.com/…" }
  ]
}
```

| 필드 | 값 |
|---|---|
| `*_ko` / `*_en` | 한국어/English. `en`이 비어 있으면 화면이 `ko`로 대신한다 |
| `name_*`, `title_*`, `bio_*`, `desc_*` | **줄 배열.** 한 줄이면 배열 원소 1개 |
| `start`, `end` | `YYYY-MM` (월 단위). `end`가 없으면(`null`) "현재/Present" |
| `career`, `education`, `certifications`, `links` | **배열 순서 = 화면 표시 순서** (보통 최신이 앞) |
| `links[].url` | `https://…` 또는 `mailto:…`. `mailto`는 새 탭으로 열지 않는다 |
| `avatar`, `avatar2x` | 프로필 사진 (선택). `frontend/assets/profile.jpg`(+`@2x`)가 있으면 스크립트가 자동으로 넣는다 |

## 2-1. 프로필 사진

이름 오른쪽에 작게(40px, 원형) 넣는다. **원본 사진은 커밋하지 않는다** — 얼굴 중심 정사각형으로 잘라 작게 압축한 것만 `frontend/assets/`에 둔다.

```
database/seed/profile_picture.png   ← 원본 (크게 찍은 사진, git 추적 안 함 — .gitignore)
        │  아래 스크립트로 자르고 압축
        ▼
frontend/assets/profile.jpg          96×96, 이 파일이 있으면 build_profile.py 가 자동으로 JSON에 넣는다
frontend/assets/profile@2x.jpg       192×192, 고밀도 화면용(선택)
```

새 사진으로 바꾸려면 `database/seed/`에 원본을 놓고, 아래와 같이 얼굴 중심으로 정사각형으로 잘라 두 크기로 저장한 뒤 `python scripts/build_profile.py`를 다시 돌린다(Pillow 필요: `pip install Pillow`).

```python
from PIL import Image, ImageOps
im = ImageOps.exif_transpose(Image.open("database/seed/원본파일")).convert("RGB")
w, h = im.size; side = min(w, h)
left, top = (w - side) // 2, int((h - side) * 0.18)  # 얼굴이 보통 위쪽에 있어 살짝 위로 자른다
cropped = im.crop((left, top, left + side, top + side))
cropped.resize((96, 96)).save("frontend/assets/profile.jpg", quality=88, optimize=True)
cropped.resize((192, 192)).save("frontend/assets/profile@2x.jpg", quality=88, optimize=True)
```

## 3. 입력용 CSV

`database/seed/`에 CSV 5개가 있다. 엑셀에서 **"CSV UTF-8(쉼표로 분리)"** 로 저장한다.

**`profile_basic.csv`** — 한 행만 쓴다.

| 열 | 설명 |
|---|---|
| `name_ko`, `name_en` | 이름 |
| `title_ko`, `title_en` | 직함/소속 |
| `bio_ko`, `bio_en` | 소개 |

**여러 줄 입력법**: 엑셀에서 셀 안에 줄바꿈을 넣으려면 <kbd>Alt</kbd>+<kbd>Enter</kbd>(Mac은 <kbd>Option</kbd>+<kbd>Enter</kbd>)를 쓴다. 그대로 CSV로 저장되고, JSON으로 옮길 때 줄마다 배열 원소 하나가 된다.

**`profile_career.csv`** — 경력마다 한 행. **최신 경력을 위쪽에** 적는다(배열 순서 = CSV 행 순서).

| 열 | 예 | 설명 |
|---|---|---|
| `org_ko`, `org_en` | `OO증권` | 회사명 |
| `role_ko`, `role_en` | `채권 애널리스트` | 직책 |
| `period_start` | `2022-03` | 시작 (YYYY-MM) |
| `period_end` | (비움) | 끝. **재직 중이면 비운다** |
| `desc_ko`, `desc_en` | `…` | 상세 (선택, 여러 줄 가능) |

**`profile_education.csv`** — 학력마다 한 행.

| 열 | 설명 |
|---|---|
| `school_ko`, `school_en` | 학교명 |
| `degree_ko`, `degree_en` | 학위·전공 |
| `period_start`, `period_end` | 입학–졸업 (YYYY-MM) |

**`profile_certifications.csv`** — 자격증마다 한 행.

| 열 | 설명 |
|---|---|
| `name_ko`, `name_en` | 자격증명 |
| `issuer_ko`, `issuer_en` | 발급기관 |
| `year` | 취득 연도 |

**`profile_links.csv`** — 링크마다 한 행.

| 열 | 예 |
|---|---|
| `label_ko`, `label_en` | `GitHub` |
| `url` | `https://github.com/…` 또는 `mailto:…` |

## 4. 화면 규칙

- **표시 순서**: 이름 → 직함/소속 → 소개 → 경력 → 학력 → 자격증 → 링크. 비어 있는 항목(배열 길이 0)은 그 구간을 통째로 생략한다.
- **경력·학력의 기간**: `2022.03 – 현재`처럼 표시한다. `end`가 없으면 "현재"(English는 "Present").
- **English가 비어 있으면** 한국어로 대신 표시한다(항목별로 따로 판단 — 예: 이름은 English가 있고 소개는 없으면, 이름은 English로 소개는 한국어로 보일 수 있다).
- **긴 내용**: 표(투자의견) 타일과 달리 이 타일은 내용이 길면 **타일 전체가 세로로 스크롤**된다. 항목 수를 제한하지 않는 대신, 소개가 아주 길면 한눈에 안 들어올 수 있다.
- **링크**: 알약 모양 버튼으로 나열한다. `mailto:`가 아니면 새 탭으로 연다.

## 5. 파일

| 파일 | 역할 |
|---|---|
| `scripts/build_profile.py` | CSV(+사진) → JSON 생성 스크립트. CSV 나 사진을 고치면 다시 돌린다 |
| `frontend/js/profile.js` | 데이터를 읽어 타일에 그린다. 언어를 바꾸면 다시 그린다 |
| `frontend/data/profile.json` | 생성된 데이터 (나중에 API로 교체) |
| `frontend/css/style.css` | `.profile-*` 스타일 |
| `frontend/js/i18n.js` | `profile.section.*`, `profile.period.present` 등 |
| `database/seed/profile_*.csv` | 입력 CSV 5개 |
| `frontend/assets/profile.jpg`(+`@2x`) | 프로필 사진 (자름·압축 완료, 커밋됨) |
| `database/schema.sql` | `profile_basic`, `profile_career`, `profile_education`, `profile_certifications`, `profile_links` 테이블 초안 (아직 적용 안 함) |
