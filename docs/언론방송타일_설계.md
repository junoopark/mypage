# 설계서 — 「언론/방송」 타일 (media)

소개 페이지 6개 타일 중 우하단 타일의 설계다. 구현이 `frontend/js/media.js`에 있다.

## 1. 요구사항과 답

**"CSV에 유튜브 주소만 넣어도 되는가?" → 된다.** 날짜·썸네일·제목을 모두 유튜브에서 자동으로 가져온다. API 키는 필요 없다.

| 항목 | 가져오는 방법 | 키 필요 |
|---|---|---|
| 제목 | YouTube **oEmbed** (`youtube.com/oembed?url=…`, 공식 공개 API) | 불필요 |
| 게시일 | 영상 페이지 HTML의 `publishDate` 값 | 불필요 (공식 API는 아님) |
| 썸네일 | 영상 ID로 만드는 고정 주소 (`img.youtube.com/vi/<ID>/…`) | 불필요, 요청조차 없음 |

## 2. 구조 — 왜 CSV → 스크립트 → JSON 인가

전략 타일(FRED/ECOS)처럼 매 방문마다 실시간으로 조회하지 않는다. 영상 제목·날짜는 한 번 올라오면 바뀌지 않으므로, **CSV를 고칠 때 한 번 스크립트를 돌려 JSON을 만들어 두는 방식**(전망·프로필 타일과 같은 방식)을 쓴다. 장점: API 키가 없어도 되고, 방문할 때마다 유튜브에 요청하지 않아 더 빠르고 안정적이다.

```
database/seed/media.csv     ← url 만 채우면 됨 (제목·날짜는 선택적으로 덮어쓸 수 있음)
        │  scripts/build_media.py 실행 (CSV 를 고칠 때마다 다시 돌린다)
        ▼
frontend/data/media.json    ← 화면이 읽는 파일 (직접 고치지 않는다)
        │
        ▼
frontend/js/media.js        ← 목록으로 그린다. 언어를 바꾸면 다시 그린다
```

## 3. CSV

`database/seed/media.csv`

| 열 | 필수 | 설명 |
|---|---|---|
| `url` | **필수** | 유튜브 주소. `watch?v=`, `youtu.be/`, `shorts/`, `embed/` 형태 모두 인식한다 |
| `title_ko` | 선택 | 비우면 유튜브 제목을 그대로 쓴다. 채우면 그 값을 우선한다(제목이 너무 길거나 맥락 설명이 필요할 때) |
| `title_en` | 선택 | 위와 같음. 비우면 마찬가지로 유튜브 제목(영문 제목이 아니어도)을 쓴다 |
| `date` | 선택 | 비우면 게시일을 자동으로 가져온다. `YYYY-MM-DD` |

행 순서는 상관없다 — **스크립트가 날짜 기준 최신순으로 정렬**해 JSON에 쓴다.

## 4. 스크립트 실행

CSV를 고칠 때마다(영상을 추가·삭제·수정할 때마다) 한 번 실행한다.

```powershell
cd 저장소 루트
python scripts/build_media.py
```

콘솔에 조회한 영상과 건수가 출력되고, `frontend/data/media.json`이 새로 만들어진다. 비공개·삭제된 영상은 조회에 실패했다는 안내와 함께 건너뛴다.

## 5. 데이터 계약 (JSON)

```json
{
  "items": [
    {
      "url": "https://www.youtube.com/watch?v=…",
      "videoId": "…",
      "title_ko": "…", "title_en": "…",
      "date": "2026-03-14",
      "channel": "…",
      "thumbnail": "https://img.youtube.com/vi/…/hqdefault.jpg",
      "thumbnailHq": "https://img.youtube.com/vi/…/maxresdefault.jpg"
    }
  ]
}
```

- `items`가 빈 배열이면 "아직 등록된 영상이 없습니다" 문구를 보여준다.
- 화면은 `thumbnailHq`(고화질)를 먼저 쓰고, 없으면 `thumbnail`(기본 화질)로 바꾼다.

## 6. 썸네일 폴백의 함정

고화질 썸네일이 없는 영상에 대해 유튜브는 **HTTP 404인데도 200처럼 보이는 120×90 회색 이미지**를 내려준다(`Content-Type: image/jpeg`가 정상적으로 붙어 있어 브라우저의 `<img>` `error` 이벤트가 발동하지 않는다). 그래서 오류 이벤트가 아니라 **로드된 실제 크기(`naturalWidth`)로 판별**해, 120px 이하면 기본 화질(`hqdefault.jpg`, 항상 존재)로 바꿔 그린다.

## 7. 화면 규칙

- 각 항목은 썸네일(왼쪽) + 제목(2줄까지) + 날짜(오른쪽 정렬 아님, 제목 아래)로 이루어진 가로 카드다.
- 카드를 누르면 유튜브 영상이 새 탭에서 열린다(`target="_blank" rel="noopener"`).
- 목록이 넘치면 프로필 타일과 같이 **타일 전체가 세로로 스크롤**된다.
- 날짜는 한국어 `2026.3.14`, English `Mar 14, 2026`.

## 8. 파일

| 파일 | 역할 |
|---|---|
| `scripts/build_media.py` | CSV → JSON 생성 스크립트 (표준 라이브러리만 사용, 추가 설치 불필요) |
| `database/seed/media.csv` | 입력 (지금은 시연용 예시 2건 — 실제 출연 영상으로 교체 예정) |
| `frontend/data/media.json` | 생성된 데이터 |
| `frontend/js/media.js` | 렌더러 |
| `frontend/css/style.css` | `.media-*` 스타일 |
| `frontend/js/i18n.js` | `media.empty`, `media.error` |

## 9. 상태 — 아직 main 에 올리지 않음

지금 CSV는 **실제 출연 영상이 아니라 동작 검증용 예시**(Rick Astley, 유튜브 최초 영상)다. 실제 채워야 하는 것은 방송·유튜브 영상 URL 목록뿐이다 — 받는 대로 CSV를 교체하고 스크립트를 다시 돌려 반영한다.
