## 3. 설계 결정

| # | 결정 | 이유 | 대안 |
|---|---|---|---|
| D1 | **모노레포 한 개** — 저장소 하나에 `frontend/`, `backend/` | 제출 GitHub 주소가 1개. Vercel·Render 모두 Root Directory 지정을 지원한다 | 저장소 2개 (W2·W3 방식) |

| D4 | **백엔드 주제: 프로필 + 방명록** | 소개 페이지 맥락에 맞고, GET·POST·검증(422)을 모두 보여줄 수 있다 | W3 가계부, W2 메모 |

## 4. 폴더 구조

```
mypage/
├─ README.md                  # 제출용 (소개 / 주요 구성 / 배포 주소)
├─ .gitignore                 # 저장소 루트 하나로 전체 관리

│   └─ 작업설계서.md           # 이 문서
├─ frontend/                  # ← Vercel Root Directory
│   ├─ index.html             # 개인 소개 페이지 (+ demo로 가는 링크)
│   ├─ demo.html              # API 연동 실습 페이지 (+ 소개로 가는 링크)
│   ├─ css/
│   │   └─ style.css
│   ├─ js/
│   │   ├─ config.js          # API_BASE_URL (로컬/배포 자동 전환)
│   │   ├─ main.js            # 공통: 다크모드 토글 등 (선택)
│   │   └─ demo.js            # API 호출·렌더링
│   └─ assets/                # 프로필 사진 등 (선택)
└─ backend/                   # ← Render Root Directory
    ├─ requirements.txt
    ├─ .env.example           # 환경변수 견본 (실제 .env는 커밋 금지)
    └─ app/
        ├─ __init__.py        # 빈 파일 (패키지 표시)
        ├─ main.py            # 앱 생성 + CORS + 라우터 조립
        ├─ schemas.py         # Pydantic 모델
        └─ routers/
            ├─ __init__.py    # 빈 파일
            ├─ profile.py     # GET /profile
            └─ guestbook.py   # GET·POST /guestbook
```

작업 중에만 생기고 커밋하지 않는 것: `backend/.venv/`, `__pycache__/`

### 5.2 backend

**`requirements.txt`** (W3과 동일, 한 줄)
```
fastapi[standard]
```

**`.env.example`**
```
# 쉼표로 구분, 끝에 / 붙이지 않는다. localhost와 127.0.0.1은 서로 다른 출처다.
ALLOWED_ORIGINS=http://127.0.0.1:5500,http://localhost:5500
```

**`app/main.py`** — 앱 생성 / CORS(환경변수) / 라우터 등록 / `/` · `/health`
```python
import os
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
from app.routers import profile, guestbook

app = FastAPI(title="Junoo Park's Page API")

origins = os.getenv("ALLOWED_ORIGINS", "http://127.0.0.1:5500,http://localhost:5500").split(",")
app.add_middleware(CORSMiddleware, allow_origins=origins,
                   allow_methods=["*"], allow_headers=["*"])

app.include_router(profile.router)
app.include_router(guestbook.router)

@app.get("/")
def read_root(): ...
@app.get("/health")
def health(): ...
```
기본 구현은 Phase 2에서 완성한다.

**`app/schemas.py`** — `GuestbookCreate`(name 1~20자, message 1~200자), `GuestbookOut`(+ id, created_at), `Profile`

**`app/routers/profile.py`** — `APIRouter(prefix="/profile", tags=["profile"])`, 고정 프로필 JSON 반환

**`app/routers/guestbook.py`** — `APIRouter(prefix="/guestbook", tags=["guestbook"])`, 모듈 안의 리스트에 저장(인메모리), 최대 50건 유지

### 5.3 frontend

**`js/config.js`** — 정적 사이트는 빌드가 없어 Vercel 환경변수를 쓸 수 없다. 접속 주소로 전환한다.
```js
const API_BASE_URL = ["localhost", "127.0.0.1"].includes(location.hostname)
  ? "http://127.0.0.1:8000"
  : "https://<Render 서비스명>.onrender.com";   // Phase 5 이후 실제 값으로 교체
```
Render 주소는 공개 정보이므로 커밋해도 된다.

**`index.html`** — 헤더 내비(소개 · API 연동 실습) / 프로필 카드 / 관심 분야 카드 (W1 카드 구조 재사용)

**`demo.html`** — 내비 / 서버 상태 확인 버튼(`/health`) / 프로필 불러오기(`/profile`) / 방명록 목록·작성 폼(`/guestbook`) / **로딩 표시**("서버를 깨우는 중… 최대 1분")

## 7. 환경별 설정 값

| 항목 | 로컬 | 배포 |
|---|---|---|
| 백엔드 실행 | `fastapi dev app/main.py` (`backend/`에서) | `uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| 백엔드 주소 | `http://127.0.0.1:8000` | `https://<서비스>.onrender.com` |
| 프론트 실행 | VS Code Live Server (`:5500`) 또는 `python -m http.server 5500 -d frontend` | Vercel 자동 배포 |
| 프론트 주소 | `http://127.0.0.1:5500` | `https://<프로젝트>.vercel.app` |
| `API_BASE_URL` | `config.js`가 자동 선택 | `config.js`가 자동 선택 |
| `ALLOWED_ORIGINS` | 기본값(코드) | Render 환경변수 = Vercel 주소 |

## 8. 배포 설정

**Render (Web Service)**

| 항목 | 값 |
|---|---|
| 저장소 | `junoopark/mypage` |
| **Root Directory** | `backend` |
| Language | Python 3 |
| Build Command | `pip install -r requirements.txt` |
| Start Command | `uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| Plan | Free |
| 환경변수 | `ALLOWED_ORIGINS` = Vercel 주소 (끝 `/` 없이) |

**Vercel (Project)**

| 항목 | 값 |
|---|---|
| 저장소 | `junoopark/mypage` |
| **Root Directory** | `frontend` |
| Framework Preset | Other |
| Build Command / Output | 비워 둔다 (정적 파일 그대로 서비스) |

**순환 의존 해결 순서**: Render는 Vercel 주소(CORS)가, Vercel은 Render 주소(`config.js`)가 필요하다.
→ ① Render 배포(CORS는 기본값) → ② Render 주소를 `config.js`에 기입 → ③ Vercel 배포 → ④ Vercel 주소를 Render의 `ALLOWED_ORIGINS`에 입력(자동 재배포).

## 11. 위험 요소와 대응

| 위험 | 증상 | 대응 |

## 12. 확정이 필요한 항목

기본안대로 진행하되, 바꾸고 싶은 것이 있으면 Phase 1 전에 알려 주면 된다.

1. **프론트 기술** — 순수 HTML(기본안) vs React. React는 Node 설치가 선행되어야 한다
2. **페이지 구성** — 2페이지 상호 링크(기본안) vs 1페이지 통합
3. **백엔드 주제** — 프로필+방명록(기본안) vs W2 메모 / W3 가계부
4. **DB** — 없음/인메모리(기본안) vs Supabase
5. **소개 내용** — 이름, 소속·역할, 소개 문장, 관심 분야, 링크(Phase 3에서 필요)
6. **Git 신원** — `user.name`, `user.email` 값(Phase 0에서 필요)
